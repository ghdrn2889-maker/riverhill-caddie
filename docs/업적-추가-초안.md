## 왜 이 개수인가

XP는 시즌(한 해)마다 0으로 돌아갑니다. 그래서 모든 등급은 **한 해 안에** 벌어야 합니다.

```
지금 비정점 천장   1,677점   (카탈로그 1,400 + '열흘의 마음' 달마다 반복 누적 277)
목표 비정점 천장   3,957점   → 성운(3,600)을 91% 수집으로
추가 필요         2,280점   31개
```

지금은 **성단(2,400)부터 도달이 불가능**합니다. 골드가 2개뿐이라 거성 위에 올라설 계단이 없습니다.

**아래는 많고 가볍게, 위는 적고 무겁게.** 거성 위가 "꾸준함·성실함의 결과"라면 거기 놓을 것은 작은 것 여럿이 아니라 큰 것 몇이어야 합니다. 작은 걸 많이 깔면 노력이 아니라 수집 노동이 됩니다.

## 채우실 때 지켜야 하는 것 (코드로 잠긴 원칙)

- **결근 개념 없음.** 안 뛴 날은 마이너스가 아니라 세지 않는 날입니다.
- **오직 +만.** 무엇도 깎이지 않습니다.
- **출근율·개근·연속 스트릭 금지.** 휴무·휴가·병가는 권리입니다.
- **순수 물량으로 압박하지 않습니다.**
- 하루 1일 규칙: 그날 한 번이라도 근무했으면 근무 1일. 54라고 세 번 치지 않습니다.
