# 백업과 이사 — 짐 싸기 · 세우기

고장 나서 되살리는 것과 다른 컴퓨터로 옮기는 것은 **같은 일**이다.
그래서 장치도 둘뿐이다: 짐을 싸는 것과, 그 짐으로 세우는 것.

## 짐 싸기

```
tools/backup-pack.sh core     # 프로그램 + 설정(.env) + 회원·정산·기록   (~5MB, 날마다)
tools/backup-pack.sh media    # 사진                                    (~75MB, 가끔)
tools/backup-pack.sh all
```

- 쌓이는 곳: `/home/ada/riverhill-backup/riverhill-<종류>-<날짜시각>.tar.zst.gpg`
- 암호: `/home/ada/.riverhill-backup-pass` (600). **이 암호를 잃으면 묶음을 영영 못 연다.**
  한 벌은 반드시 그 컴퓨터 밖에 둔다.
- 회원 파일(`app.db`)은 돌아가는 중에도 `VACUUM INTO` 로 한 순간의 온전한 사본을 뜬다.
- **★묶은 뒤 반드시 다시 풀어서 확인한다** — 회원 파일을 실제로 열어 표와 사람 수를 센다.
  확인에 실패하면 묶음을 안 남기고 실패로 알린다.
- 보관: 알맹이 90개 · 사진 8개 (넘으면 오래된 것부터 걷는다)

묶음 속 생김새 — `WHAT.txt` · `app/`(프로그램·부품·.env) · `data/`(사진 뺀 데이터).
부품(node_modules)까지 들어 있어 **인터넷 없이도 세울 수 있다.**

## 세우기

```
tools/backup-restore.sh /어디에/세울까              # 시험 — 기본
tools/backup-restore.sh /어디에/세울까 --media auto  # 사진까지
tools/backup-restore.sh /어디에/세울까 --live        # ★진짜로 세운다
```

- **기본은 '시험'이다.** 바깥 열쇠(네이버·카톡·AI·인제스트)를 다 비우고, 알림을 두 겹으로 끄고,
  알림 열쇠는 시험용 새것을 만들어 준다. 3200/3210 자리에 127.0.0.1 로만 선다.
  → 사본이 회원에게 알림을 두 번 보내거나 카페를 두 번 긁는 일이 없다.
- `--live` 는 열쇠를 그대로 두고 3000/3100 에 세운다. **진짜 이사·복구일 때만.**
- 돌고 있는 앱 자리·집 폴더·너무 얕은 자리에는 안 푼다.
- 세운 뒤 실제로 열어 보고(HTTP 200) 회원 수를 세어 보고한다.

## 알아 둘 것 (연습에서 드러난 것)

- **알림 열쇠(VAPID)를 비우면 앱이 아예 안 뜬다.** 그래서 시험판은 비우지 않고 새로 만든다.
- 프로그램 보관소는 공개라 받는 데 열쇠가 필요 없다. 그래도 묶음에 프로그램을 같이 넣는다 —
  **데이터와 짝이 맞는 바로 그 판본**이어야 하기 때문이다.

## 날마다 저절로

```
tools/backup-nightly.sh      # 새벽 3:20 에 crontab 이 부른다
tools/backup-status.sh       # 어떻게 돌고 있나 한눈에
```

- 날마다 알맹이, **일요일엔 사진까지**.
- 돈 결과는 `/home/ada/riverhill-backup/STATUS.txt` 한 장에 적힌다. 기록은 `backup.log`.
- 집 밖 보내기는 `/home/ada/.riverhill-offsite` 에 보낼 곳이 한 줄 적혀 있을 때만 한다.
- **★보내기만 하고 저쪽 것을 지우지 않는다** — 여기가 통째로 날아가도 저쪽은 남는다.
  아주 오래된 것(180일)만 걷는다.

## 집 밖 한 벌 — 구글 드라이브

```
tools/gdrive-connect.sh      # 한 번만. 리눅스 화면에서 실행(바탕화면 아이콘도 있다)
```

브라우저가 열리고 '허용'만 누르면 끝난다. 권한은 `scope=drive.file` 로 좁혀
**rclone 이 만든 파일만** 볼 수 있다 — 드라이브의 딴 파일에는 못 닿는다.
이어지면 `/home/ada/.riverhill-offsite` 에 보낼 곳이 적히고, 그때부터 새벽마다 간다.

## 플레이스토어 앱 서명 열쇠

`riverhill-appkeys-<날짜>.tar.gz.gpg` — 잃으면 **앱 갱신을 영영 못 올린다.**
signing.keystore · 그 열쇠의 암호 · assetlinks.json 이 들었다(설치파일은 뺐다 — 다시 만들 수 있다).

- **평문이 서버를 지나가지 않는다.** 윈도우에서 잠가서 잠긴 채로 올린다.
- 날마다 바뀌는 것이 아니라 한 번 올려 두면 된다. 열쇠가 바뀔 때만 다시.
- 날마다 도는 보내기는 `riverhill-*.gpg` 를 챙기므로 이 꾸러미도 같이 간다.
  **오래됐다고 걷는 대상에는 안 들어간다** — 영원히 둔다.
- 푸는 법: `gpg --decrypt` → tar.gz. 암호는 백업 암호와 같다.

## 아직 안 한 것

- 라이트세일 서버에도 한 벌 (그 서버가 아직 이 컴퓨터의 열쇠를 안 받는다)
